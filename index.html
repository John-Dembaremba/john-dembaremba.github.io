About me

I am a software developer based in Harare, Zimbabwe, working across frontend web development, mobile applications, backend engineering, and blockchain development. I enjoy translating business requirements into practical software with clear interfaces and maintainable code.

On the frontend, I work with React, Next.js, JavaScript, and TypeScript to build web applications. For mobile, I use React Native and Expo, with Kotlin for native Android integrations and offline functionality.

My backend work uses Go, Python, Django, and FastAPI for APIs, business workflows, data processing, and system integration. My blockchain projects combine Solidity smart contracts with web interfaces and wallet integration.

At ZETDC, I contribute to business systems and operational applications as a System Support Officer (Programmer). My work spans implementation, testing, debugging, deployment support, and user documentation.

Recent independent work includes reusable offline authentication packages and Ramus, an email-first campaign platform in development. Across projects, I value thoughtful system design, automated testing, and software that people can use confidently.
