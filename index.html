About me

I am a software developer based in Harare, Zimbabwe, with a BSc (Hons) in Informatics. My focus is backend engineering with Go and Python, supported by practical experience building web and mobile applications.

At ZETDC, I work as a System Support Officer (Programmer), implementing business requirements, integrating systems, testing and debugging software, and supporting deployment and user documentation.

My recent work includes a three-package offline authentication ecosystem spanning Django, native Android, and React Native. It connects encrypted credential issuance with local password verification for applications that need to work without an internet connection.

I am also building Ramus, an email-first campaign platform. I care about clear architecture, dependable background processing, automated tests, and maintainable deployments.

Reusable Django package for issuing encrypted, expiring offline credentials. Supports per-user enablement, credential rotation, and synchronization snapshots.
